This folder contains all datasets used in the EMFMA case study. Below is a description of each file:

adm_x.csv:
Contains uncertainty ranges for transfer coefficients in the ADM module, based on processed expert elicitation data.

elicitation_1.xlsx:
Elicitation file used in the current analysis, reflecting the expert's input. Alternative versions are available in the elicitation/ folder.

levers.csv:
Defines the implementation of policy levers within the plMFA model.

mfa_x.csv:
Contains uncertainty ranges for transfer coefficients in the MFA module, derived from processed expert elicitation data.

performance_metrics.csv
Specifies how the performance metrics (microplastics, macroplastics, and secondary material) are calculated, including which sinks are considered and the thresholds for success.

*Removed files (not ready for publication):*

backgrounddata.xlsx:
Provides the background data required to run the plMFA model.
