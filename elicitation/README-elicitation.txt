This folder contains several elicitation-related files used in the EMFMA case study. Below is a description of each file:

constrained_elicitation_0.xlsm:
Blank version of the constrained elicitation survey to be completed by an expert.

constrained_elicitation_1.xlsm:
Completed survey filled out by the expert, containing constrained uncertainty estimates.

constrained_elicitation_template.xlsm:
Template version of the constrained elicitation procedure for the development of your own survey.

elicitation_0.xlsx:
Elicitation file formatted for loading into Python, containing no data.

elicitation_1.xlsx:
Elicitation file formatted for loading into Python, containing the data from constrained_elicitation_1.

elicitation_2.xlsx:
Elicitation file formatted for Python, containing parameter values from the original plMFA model.
